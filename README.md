# 🛍️ Basic SQL Case Study : Retail Store POS Data Analysis
  
  This project analyzed Retail Store Point of Sale (POS) data to understand customer behavior and revenue performance. Tasks included data preparation (converting dates to a valid format and determining the transaction time range)  and extensive data analysis. Queries determined customer demographics (gender count, max city count) , analyzed transaction metrics (most frequent channel, maximum quantity ordered, customer transaction count) , and calculated total revenue across various categories (e.g., Electronics, Books) and store types. It also involved calculating the percentage of sales and returns by product sub-category.
